# 一键部署前填写信息清单

> 不要把真实密码写进这份 Markdown。真实秘密只在部署器弹窗中填写。

## VPS

### 推荐配置

| 使用强度 | CPU | 内存 | 硬盘 | 适用情况 |
| --- | ---: | ---: | ---: | --- |
| 个人基础使用 | 2 核 | 4GB | 50GB SSD | 当前默认方案，可以动态排队处理文件 |
| 大量或长期批量传输 | 4 核 | 8GB | 80～100GB SSD | 给容器、并发任务和 CloudDrive2 缓存留下更多余量 |

- 推荐 Ubuntu 22.04/24.04 或 Debian 12 64 位；
- 必须支持 `/dev/fuse`，并具有 root 或可用的 sudo 权限；
- 推荐公网 IPv4，或者其他能够从本地稳定建立 SSH 连接的地址；
- VPS 应能稳定访问 Telegram 和 Docker 镜像仓库；
- 端口带宽建议 100Mbps 或以上，并准备足够的月流量。每个文件都要经过 VPS 下载和上传，
  服务商可能只统计出站，也可能同时统计入站与出站，应以服务商计费规则为准；
- CloudDrive2 的内部缓存不受 20GB 任务预算直接控制。50GB 硬盘可以使用，但批量传输时应
  关注真实剩余空间；经常处理大量文件时优先选择 80～100GB。
- 单文件超过本地任务预算时会自动使用流式模式，不需要把预算调到文件大小；流式中断后
  会从头重试，CloudDrive2 仍可能使用自己的缓存。
- Windows 部署器会只读检测当前 VPS，并给出“均衡模式”和“流式优先”两套实例级预算／
  保留线建议。源码默认仍是 20GB/20GB；检测不会静默修改，用户点击应用后才改变本次表单。
- 部署器不会自动分区、扩容或格式化磁盘。若以后使用独立数据盘，应先由用户或服务商完成
  挂载，再把安装目录明确配置到 `/opt/` 下对应的安全路径。
- Docker 数据目录若位于另一文件系统，两边都必须保留足够空间和 inode；部署器会分别检查。
- 历史升级备份超过 5GB 时会提示。部署不会自动删除，可先用 `manage.sh backups` 查看，再
  显式使用 `manage.sh prune-backups N` 按类型保留最近 N 份。

### 需要填写

- [ ] VPS IP 或域名
- [ ] SSH 端口
- [ ] SSH 用户名
- [ ] 登录方式：密码 / SSH 私钥
- [ ] VPS 密码，或者 SSH 私钥文件
- [ ] 私钥口令（如果有）
- [ ] sudo 密码（非 root 且非免密 sudo 时）
- [ ] VPS 系统为 Ubuntu / Debian 64 位
- [ ] VPS 支持 `/dev/fuse`
- [ ] 磁盘至少约 50GB
- [ ] 内存至少 4GB

## Telegram

- [ ] Bot Token
- [ ] Telegram API ID
- [ ] Telegram API Hash
- [ ] 本人 Telegram 数字 ID

## CloudDrive2 / 115

- [ ] CloudDrive2 会员账号；当前方案按会员环境设计，并要求 115 挂载和 WebDAV 功能可用
- [ ] WebDAV 用户名
- [ ] WebDAV 密码
- [ ] 115 已准备好由本人登录或扫码
- [ ] 115 剩余空间足够；115 会员不是程序代码的硬性要求
- [ ] 确认 WebDAV 根目录；若已经选中目标 Telegram 文件夹，子目录留空
- [ ] 登录并挂载后执行“WebDAV 验收（写入测试文件）”
- [ ] 验收界面明确显示 `TG115_DESTINATION=OK`

CloudDrive2 会员账号及 115 登录只在 CloudDrive2 管理页由本人操作，不填写进部署器，也不
提交到 GitHub。部署器需要的是你在 CloudDrive2 中另外设置的 WebDAV 用户名和密码。

## 默认值与实例建议

- [ ] 安装目录：`/opt/tg115`
- [ ] 本地任务预算：源码默认 `20GB`；测试 SSH 后按需应用实例建议
- [ ] 磁盘最少保留：源码默认 `20GB`；与本地预算使用同一份实例建议
- [ ] 时区：`Asia/Shanghai`
- [ ] 勾选“在 VPS 上安装并管理 CloudDrive2 容器”

## 明确不需要提供

- Telegram 私人账号密码；
- Telegram 二次验证密码；
- 115 密码给 Codex；
- CloudDrive2 会员账号密码或登录 Cookie；
- GitHub 账号密码。
